## 次のステップ

### 1. 実装の作成（Green）
`App.tsx`に以下の実装を追加する必要があります：

```typescript
useEffect(() => {
  // ゲーム初期化処理
  try {
    // 1. ReactUIBridgeのインスタンス作成
    const bridge = new ReactUIBridge();
    
    // 2. GameManagerのインスタンス作成
    const gameManager = new GameManager(bridge);
    
    // 3. ステージデータの読み込み
    const stage = STAGE_MASTER[1]; // デフォルトでステージ1
    
    if (!stage) {
      console.error('ステージデータが見つかりません');
      return;
    }
    
    // 4. ゲーム開始
    gameManager.startGame(stage);
  } catch (error) {
    console.error('ゲーム初期化に失敗しました:', error);
  }
}, []);
```

## モックの構成

### GameManagerのモック
- `startGame`: ゲーム開始処理のモック

### ReactUIBridgeのモック

## 技術的な注意点

### 1. モックの設定
- `vi.mock()`を使用してモジュール全体をモック化
- テストごとに`vi.clearAllMocks()`でモックをリセット
- ストアも`beforeEach`で初期化

### 2. 非同期処理
- `waitFor()`を使用して非同期処理の完了を待機
- `useEffect`の実行を待つため、レンダリング後の状態変化を確認

### 3. 依存関係の管理
- テストは`core/`、`bridge/`、`store/`の実装に依存
- モックを使用して実装の詳細から分離
